## Problems fixed during QA

- Live WebMCP adapters crashed when the browser supplied no invocation abort signal. They now tolerate the absent signal while preserving cancellation, edit authorization and lock checks; regression tests cover both absent options and empty options.
- Small typography, wrapping toolbar controls, weak metric hierarchy and overly wide initial layout were corrected.
- Automatic agent placement now uses three columns and adequate card clearance; a regression checks all nine demo cards for overlap.
- Fit View reserves room for the simulation banner and minimap. Simulation badges sit above cards and long impact labels wrap.
- Comparison labels and fields no longer truncate; before/after values are larger; item selection opens the inspector and closes the comparison overlay.
- Reset returns to Inspect and refits a revision-zero architecture. Sidebar input alignment and empty-inspector spacing were corrected.
- Agent simulation previously left manual controls on an unrelated component target. They now reflect the current simulation, including a repeated external target.
- Dark/light muted text contrast, simulation edge arrow colors, and header count layout were corrected.
- Comparison ignores object key insertion order, preventing false changes after equivalent serialization.

## Remaining visual / verification limitations

- Desktop layout remains intentionally limited to widths of at least 1000 px. Mobile was outside this request.
- At 1280 px, fitting the full nine-node graph scales secondary node metadata to roughly 8–9 px and titles to roughly 10 px. Use focus or zoom for configuration details; the system summary and sidebar remain larger. Larger 30–50-node graphs necessarily require pan/zoom.
- Catalog names, architecture breadcrumbs, and some secondary labels may truncate with full labels available through accessible names, tooltips, or inspection. Long inspector and comparison lists require scrolling.
- 30–50-node browser animation/drag performance has not been measured; only the domain/comparison workload was measured.
